# .editorconfig

Filename-only stub for repository editor settings. It establishes two-space indentation, LF line endings, UTF-8, trailing-whitespace trimming, and final newlines at `.editorconfig:1-9`; Markdown is exempt from trailing-whitespace trimming at `.editorconfig:11-12`.
